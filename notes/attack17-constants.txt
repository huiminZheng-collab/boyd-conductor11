第四部分：常数 C_x, C_y 的精确确定（单位根）
--------------------------------------------
关键观察: 在 ord 为 0 的尖点处取**值**。ord_{4/11}(U) = 0 = ord_{4A}(x_B),
ord_{3/11}(V) = 0 = ord_A(y_B)。函数在尖点的值是 chart 无关的:
    (x∘π)(4/11) = x_B(π(4/11)) = x_B(4A) = x_B((0,−1)) = (0+(−1))/(0−1) = 1,
    (y∘π)(3/11) = y_B(π(3/11)) = y_B(A)  = y_B((0,0))
                = ((0−1)³ − (0+0)(0+1))/(0−1)² = −1
（用到第五部分的精确尖点表 m: π(4/11) = 4A, π(3/11) = A; x_B, y_B 为
attack16 的有理映射, 在 ℤ 点取值是精确有理运算）。
而 U 在 4/11 的值 = κ_{4/11}(U) = −1, V 在 3/11 的值 = κ_{3/11}(V) = −1, 故
    C_x = (x∘π)(4/11)/U(4/11) = 1/(−1) = −1   （精确）
    C_y = (y∘π)(3/11)/V(3/11) = (−1)/(−1) = +1 （精确）
两者皆为 ±1 ⟹ log|C_x| = log|C_y| = 0 精确 ⟹ 修正项
